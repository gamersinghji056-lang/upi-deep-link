Connection flow

1. Install & open APKApp shows exactly what device information it needs before connection.
2. Verify mobile/SIMBind the device using OTP to the mobile number present on that phone. Do not rely on silently reading the SIM phone number because Android often does not expose it.
3. Grant permissionsRequest permissions one by one with a clear reason and allow the user to deny optional diagnostics.
4. Pair deviceCreate a one-time pairing token from this dashboard and exchange it for a device credential.
5. Collect payment resultCapture UTR from the UPI app result/callback when available. Do not treat app return alone as successful payment.

DIAGNOSTIC
SIM / subscription metadata
Use best-available subscription/carrier identifiers only after consent. SIM-bound access should be enforced with OTP verification.
CONSENT
UPI transaction result
Read the result returned by the payment flow and extract the UTR where the app provides it.
PAYMENT
We should not request SMS, contacts, call logs or notification access just to obtain a UTR. If a UPI app does not return the UTR, use verified backend status or explicit user entry instead of covertly reading unrelated phone data.
